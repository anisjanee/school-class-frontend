# School Journal Pro

Полноценный локальный школьный журнал: frontend + FastAPI + SQLite. Основной кабинет находится в `portal.html`.

## Роли и права

### Администратор
Автоматически создаётся при первом запуске:

```text
admin@school.local / Admin123!
```

Администратор имеет полный контроль:
- создаёт учителей, учеников и родителей;
- включает/отключает аккаунты;
- меняет пароли и привязки;
- добавляет и редактирует учеников;
- создаёт предметы и назначает учителей;
- полностью управляет расписанием;
- управляет оценками и домашними заданиями;
- использует сообщения и уведомления.

### Учитель
- просмотр учеников;
- выставление и удаление оценок;
- создание и управление своими домашними заданиями;
- просмотр расписания;
- сообщения.

### Ученик
- свои оценки;
- расписание своего класса;
- домашние задания своего класса;
- сообщения.

### Родитель
- данные привязанного ребёнка;
- оценки ребёнка;
- расписание;
- домашние задания;
- сообщения.

## Основные возможности

- регистрация ученика/родителя;
- серверная авторизация и Bearer-сессии на 24 часа;
- PBKDF2-HMAC-SHA256 для паролей;
- SQLite;
- оценки 1–10 и комментарии;
- расписание Пн–Сб;
- домашние задания;
- сообщения и отметка прочитанного;
- уведомления;
- автоматическая миграция старой таблицы пользователей на схему с ролью `admin`;
- адаптивный dashboard и мобильная версия.

## Локальный запуск

### 1. Backend

```bash
cd backend
python3 -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
uvicorn main:app --reload --host 127.0.0.1 --port 8000
```

Windows PowerShell:

```powershell
.venv\Scripts\Activate.ps1
```

API:

```text
http://127.0.0.1:8000
http://127.0.0.1:8000/docs
```

### 2. Frontend

В отдельном терминале из корня проекта:

```bash
python3 -m http.server 5500
```

Открой:

```text
http://127.0.0.1:5500/portal.html
```

В GitHub Codespaces открой вкладку **PORTS** и используй порты `8000` и `5500`.

## Важно

Новая версия backend автоматически обновляет старую схему `users` и сохраняет существующие аккаунты/данные. Перед массовыми изменениями рекомендуется иметь копию `backend/school.db`.

`index.html` и связанные с ним `script.js/style.css` сохранены как старый статический интерфейс. Для новой системы используй `portal.html`.
